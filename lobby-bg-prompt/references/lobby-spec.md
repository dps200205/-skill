# 大厅背景图制作规范

来源：7 张项目优秀案例（流浪地球 / 灵音都市 / 9月版本 / 吞噬星空/ 周年庆 / 封神榜 / 赏金爆破）的量化与结构分析。以下数值为实测，非通用美术常识。

---

## 一、输出规格

- **分辨率**：6532 × 2538 px（7/7 张案例完全一致）
- **宽高比**：约 2.574 : 1（超宽画幅，接近 2.55:1）
- 提示词中必须显式声明超宽比例，否则生图模型默认输出 16:9，构图会全盘失效
- 英文写法建议：`ultrawide 2.57:1 cinematic aspect ratio, panoramic composition, 6532x2538`

---

## 二、构图与视觉引导

### 功能分区结构（横向分区，最重要的一条）

依据项目规范图（核心区左置 / 核心区右置两张）实测提炼。画面按职能分三个功能区：

| 区域 | 位置 | 职能 | 内容规则 |
|---|---|---|---|
| **视觉核心区** | 宽约 23% 的纵向带。**左版**：横向约 20%–43%；**右版**：横向约 53%–76%。从画面顶部一直延伸到地面线 | **最主要视觉焦点、主体物、画面核心所在** | 主体叙事物、核心标志物必须放在这条带内。它是全画面细节最丰富、对比最强、最先被看到的位置 |
| **地面区** | 从画面底部向上约 **30%**（28%–35%） | 角色站位与 UI 承载 | 平整铺装 + 透视纹理，见第九节 |
| **次要内容区·次要内容区** | 其余全部区域 | 氛围、陪衬、纵深 | 中远景结构、天空、氛围介质。信息量低于视觉核心区，但不允许空 |

**角色站位**：角色紧贴**核心区内缘、靠近画面中轴**站立（约在横向 45%–55%）——即角色站在视觉核心区的旁边，而不是被它挡住。中央留空区就是为这个角色位服务的。

**两个版本的选用**：
- **方案一与方案二：强制左版**（视觉核心区在画面左侧，视觉中心在左）
- **方案三与方案四：自由**，可选左版或右版，但同一次输出里建议左右各一，增加差异

**关键澄清**：留空是**横向的、近处的**概念，位于中轴附近的角色区。视觉核心区虽然靠近中央，但它的主体物位于中景/中远景的纵深处，不妨碍近处的角色站位。

**实测支撑**：7/7 张案例中央区平均亮度均高于左右边缘，差值 30–82灰阶。这个"中亮边暗"是刚性规律。注意这个"边暗"由**暗部渐变**实现，不靠大块实体遮挡——见第五节 L1。

### 引导方式

一切引导的终点都是**视觉核心区**：

1. **透视线引导**——地面纹理 / 甬道 / 轨道的透视线向纵深汇聚，消失点落在核心区内，把视线推向视觉核心
2. **地面与环境的自然引导**——地面上的元素与纹理（灯带、铺装缝线、反光条、轨道）和周围环境元素（结构边缘线、阵列排布、植被走势）形成**合理自然的引导线**，指向核心区主体。可以是直线汇聚，也可以是**曲线引导**（弧形灯带、弯曲甬道、环流纹理）
3. **明暗与色彩引导**——最亮的高光锚点在核心区内；点缀色集中用于核心区主体，次要内容区降低饱和
4. **双侧轻量收边**——左右都有暗部渐变收边，但**体量必须不等**（详见下节）

### 对称性：强制非对称平衡（硬性要求）

**禁止镜像对称构图。** 这是本项目的明确取向——对称构图会让画面呆板、像样板间。

注意区分两个概念，别搞混：

- **双侧收边**是功能需求 → 必须保留（左右都有暗部渐变）
- **左右对称**是形式选择 → 必须避免

打破对称的五个手段，**每段提示词至少用 3 个**：

1. **核心区偏置**：视觉核心带天然在左或在右，绝不在正中——这是最大的非对称来源
2. **消失点偏心**：消失点落在**核心区范围内**（左版横向约 25%–40%，右版约 60%–75%），绝不放在 50% 正中
3. **地面光影与纹理不对称**：地面的光带、长影、反射、纹理疏密左右不等，一侧重一侧轻
4. **高光锚点偏心**：最亮点在核心区内，不与画面中轴重合
5. **两侧内容不同类**：两侧次要内容区的内容类型、密度、高度都要有差异

**自检**：如果把画面左右翻转后看起来差别不大，说明对称了，必须重写。

英文写法必须显式声明：`asymmetrical composition, main visual focus zone placed off-center on the left or right third of the frame, vanishing point inside the focus zone, avoid mirror symmetry`

## 三、地平线与视线高度（硬指标）

### 地平线位置：从画面底部向上约 30%

**地面与背景的交界线，落在从画面底部向上约 30% 处**（等价于从顶部向下约 70%），可接受浮动区间 **28%–35%**（均从底部向上量）。此数值来自项目规范图地面区实测（31%）。

> 修订说明：地平线量取方向**一律从底部量**。此前曾用过 40%（底部量），现依据项目规范图实测值修订为 **30%**——地面占下部约 30%，上部约 70% 为天空与中远景叙事区。

这个定义的连带影响，必须同步执行：

- **地面占画面下部约 30%**（规范图地面区）。地面是角色站位与 UI 承载区
- **上部约 70% 为天空 + 中远景叙事区**——这部分**不是天空留白**，地标建筑、巨构、悬浮物、山体、穹顶、巨物剪影都在这里展开
- 天空本身仅作为剪影背板与光源，**不允许出现大面积空白天空**；上部区域要被中景上部与中远景结构充分填充

提示词写法：`horizon line at approximately 30 percent of frame height measured from the bottom (about 70 percent from the top), ground plane occupying the lower 30 percent, upper area densely filled with midground and background structures rather than empty sky`

### 相机高度与角度

- **平视或微弱仰视**（仰角 0°–5°）。相机架在成年人站立视高附近，视线水平或微微上扬
- **绝对禁止**：任何形式的俯视（哪怕轻微俯视也不行）、大仰视、鸟瞰、斜角荷兰角
- 微弱仰视能让核心区内的主体（地标 / 巨构 / 塔楼）显得更宏伟，这是项目需要的史诗感来源；但**仰角不得超过 5°**，过大会导致前景变形、地面消失
- **消失点必须恰好落在地平线上**（纵向对齐地平线），横向落在**核心区范围内**（左版约 25%–40%，右版约 60%–75%，见第二节）

提示词写法：`eye-level camera or very slight low angle looking up no more than 5 degrees, absolutely no top-down view, vanishing point exactly on the horizon line and inside the off-center focus zone`

## 四、相机参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 等效焦段 | 24–35mm（广角，但非鱼眼） | 灵音都市/吞噬星空偏 24mm 的舒展感；封神榜偏 35mm |
| 透视畸变 | 轻微，直线基本保持直 | 不要鱼眼弯曲 |
| 景深 | 深景深，前中远全清晰 | 大厅图需要全画面可读，不做浅景深虚化 |
| 大气透视 | 强| 远景明显发灰、降饱和、提亮，与前景形成对比 |
| 曝光倾向 | 中央过曝倾向，边缘欠曝 | 服务于"中亮边暗" |

英文写法：`24-35mm wide angle lens, eye-level camera, deep focus, strong atmospheric perspective, vanishing point centered on horizon`

## 五、画面层次关系（五层制）

**叙事与主题的中心在中景或中远景。** 这是本规范的核心取向：前景只做低矮收边，中景与中远景共同承担内容主体。绝不能出现"前景高大物体遮挡两侧、中远景空旷"的结果。

层数为**五层**，关键是把"远景"拆成中远景与远景两层，避免中间断档——断档正是画面显空的直接原因。

### L1 前景（**不放任何物件，聚焦于地面设计**）

**前景不摆放任何物体**——大、中、小型物件一律不放，没有例外。前景的内容就是**地面本身**：

- 前景 = 干净的铺装地面 + 暗部渐变 + 贴地光影 + 薄雾
- 地面的设计三要素（引导 / 纹理 / 结构）见本节末尾「地面」小节，那是前景设计的全部手段
- **禁止出现任何贯穿画面全高或大半高度的前景结构**——高耸的建筑侧壁、岩壁、门楼、廊柱、大型机械等一律不允许出现在前景。这类结构如果必须存在，只能放在中景（见 L2）
- 亮度最低，细节适度隐入暗部。**职能是承托与引导，不是看点**
- **警告**：前景是大厅图最常做错的层——任何物件都会抢戏、遮挡、让画面显脏。两侧上方必须通透，前景越干净越好

提示词写法：`foreground completely free of objects, no props no debris no structures in the near field, only clean ground paving with a soft dark gradient at the outermost edges, ground-level light and shadow play, thin haze, upper sides of the frame kept open and unobstructed`

### L2 中景（叙事中心之一 + 画面引导层）

- **中景可以作为叙事的中心和主题的位置中心**——主体建筑 / 装置 / 雕塑 / 地标 / 画面核心标志物可以放在这一层
- 同时**承担一部分画面引导作用**：中景结构的边缘线、透视线、明暗对比要把视线引向深处，与地面的透视汇聚形成合力
- 建筑侧壁 / 岩壁 / 门楼 / 廊柱 / 机械结构 / 残墙等**中大型结构允许放在中景**（前景不允许），但每侧至多一组，且服务于引导与叙事，不堆砌
- 亮度中等偏亮，细节丰富
- 横向偏置于 1/3 或 2/3，不占中央留空区

### L3 中远景（叙事中心之一，**最易被忽略、必须写足的一层**）

- **中远景同样可以作为叙事的中心和主题的位置中心**——与中景二选一或两者配合：主体在中景时，中远景做纵深陪衬与氛围延展；主体在中远景时，中景退为引导与过渡
- 位于中景之后、远景之前，**填充地平线上方区域的主体**；**核心区内的主体物就放在这一层或 L2**
- 内容：主体地标 / 次级建筑群 / 塔楼阵列 / 悬浮平台 / 巨型骨架 / 山体中段 / 巨构侧翼（**不使用桥、连廊类横向跨越结构**，见「桥元素警示」）
- 明度介于中景与远景之间，细节丰富，**必须有可辨识的结构轮廓**
- **这一层缺失就会出现"中远景空旷"**。硬性要求：**至少写出 2–3 组具体的中远景结构物**，并交代它们的前后遮挡与纵深关系
- 手法：沿纵深方向做**层层递退的剪影叠压**（近的深、远的浅），至少 3 个纵深梯度

### L4 远景背景（最亮、最灰，但不等于空）
- 天空 / 巨型天体 / 极远山峦 / 穹顶 / 云层
- 最高明度、最低饱和，细节最少
- **但必须有内容**：即使是天空，也要有云层结构、天体、光带、极远剪影。**禁止大面积纯色空白天空**
- 天空位于上部 60% 区域内，作为剪影背板与光源，配合云层结构与光带，不做纯色留白

### L5 氛围介质（贯穿全画）
- 体积光 / 雾气 / 飘浮粒子 / 光束 / 能量流
- **用大气透视把 L2/L3/L4 明确分层**：每往后一层，对比度降低、明度提高、饱和度下降
- 前景粒子大而模糊，远景粒子小而密

### 地面（横跨画面下部约 30%，规范图地面区）——前景设计的全部内容

前景既然不放物件，**地面就是前景唯一的设计载体**。以下来自 8 张案例地面区域的逐一分析，三种手段必须同时使用：

#### 地面引导（指向视觉核心区，最重要）

案例中反复出现的引导手法，每段提示词至少用 **2 种**：

1. **铺装分格缝透视汇聚**——板块接缝线向纵深汇聚，消失点落在视觉核心区内（流浪地球、灵音都市、封神榜）
2. **嵌入式发光导引条**——灯带 / 光缝嵌入地面，沿纵深或弧线指向主体（灵音都市的黄绿光带、赏金爆破的金色几何光带、9月版本的紫色光痕）
3. **光带扫射 / 长影投射**——一道光或长影横扫地面对角线，把视线带向主体（流浪地球的斜向光影、周年庆的强光带反射）
4. **反射引导**——湿润或高反射地面把主体与光源倒映进来，倒影本身构成指向主体的视觉线（周年庆、灵音都市、9月版本）

#### 地面纹理细节（近看有内容，但不能乱）

- **板块接缝**：大板 + 清晰缝线，缝线是唯一必须的纹理（8/8 张都有）
- **嵌线与图案**：菱形嵌块（封神榜）、几何折线光带（赏金爆破）、同心涟漪纹（灵音都市）、裂纹透光（吞噬星空）——每段只选 1 种，不混用
- **材质微差**：相邻板块间的明度/色温微小差异，或局部湿润反光变化
- **极轻覆盖物**：散落花叶、薄尘、细雪可以有一层，点到为止
- **纹理必须服从透视**：所有缝线、嵌线、光带都服从同一消失点，绝不能出现与透视无关的随机纹理

#### 地面结构（大关系）

- **大板铺装**：超大规格板块（2m 以上），绝不能是小砖碎拼
- **平整连续**：无起伏、无台阶、无断差（第九节硬指标）
- **中央最简**：板块密度与纹理强度在中央站位区最低，向两侧与中远景渐强——纹理的"疏密梯度"本身也是引导

提示词写法：`ground as the sole design carrier of the foreground, large flat paving panels with perspective-converging seams, embedded luminous guidance strips pointing toward the main subject, a sweeping light band and long shadows across the ground, subtle reflections mirroring the subject, texture density lowest at the center and increasing toward the sides`

### 信息密度分配（重要）

```
前景（极疏，仅地面纹理与光影，无任何物件）→ 中景（密，叙事中心之一 + 引导）→ 中远景（密，叙事中心之一，撑满上部区域）→ 远景（疏，大气透视简化）
```

### 信息密度分配（重要）

```
前景（极疏，无任何物件，仅地面纹理与光影）→ 中景（密，叙事中心之一 + 引导）→ 中远景（密，叙事中心之一，撑满上部区域）→ 远景（疏，大气透视简化）
```

注意"中央留空"指的是**中央不放大体积遮挡物**，不等于中央纵深方向也要空。中央区的**纵深处**应当填满层层递退的中远景结构，只是它们位置足够远、体量足够小，不妨碍 UI 与角色。**留空是横向的、近处的；纵深是要有内容的。**

### 桥元素警示（高频失控项）

生图模型在这类宽画幅场景提示词下**极易自发加入莫名其妙的桥**（天桥、连廊、栈桥、拱桥、悬索桥等）。规则：

- **提示词正文不写任何桥类词汇**——不主动使用桥、天桥、连廊、栈桥、高架桥、拱桥、悬索桥、廊桥，英文同理不写 bridge / skybridge / footbridge / walkway / overpass / viaduct
- 中远景需要"横向连接"或"跨越感"时，用**非桥结构**替代：高低错落的塔楼轮廓、层叠递退的楼体剪影、悬浮平台群、环形结构、山体层叠、阵列柱林、分层云带与光带
- **桥类词汇全部进负面提示词**（见第十节）
- 即使用户的创意里提到桥，也优先转译为其他结构（如把"跨海大桥"转译为"沿岸递退的防波堤与灯塔阵列"），除非用户明确要求保留桥

## 六、光影与色彩

### 光比结构（刚性）

```
中远景高光锚点（最亮）→ 中景主体（中亮）→ 地面（中）→ 左右前景（最暗）
```

- 主光来自**纵深处**，逆光/半逆光打亮中景与中远景主体的轮廓
- **高光锚点偏离中轴**（跟随偏置的主体），不要放在画面正中——那会强化对称
- "中央亮、两侧暗"仍然成立，指的是**横向的明度分布趋势**（中间一带亮、左右压暗），不是"正中一个圆形亮斑"
- 前景低矮物体处于阴影中，靠环境光和反光提亮细节
- 四角有自然暗角，但不是后期硬加的黑角
- **用明度差把L2/L3/L4 拉开**：三层之间每层至少有可辨识的明度台阶，这是层次感的直接来源

### 配色

- **主色调统一**：整张图收敛在 1 个主色调内（青蓝 / 紫粉 / 金橙 / 黄绿），不做多色混战
- **1 组对比色点缀**：用互补色做视觉焦点。案例中的组合：
  - 冷蓝 +暖红（流浪地球、吞噬星空）
  - 青灰 + 荧光黄绿（灵音都市）
  - 紫+ 白光（9月版本）
  - 紫蓝 + 金橙 + 品红（周年庆、赏金爆破）
  - 暖黄 + 青绿（封神榜）
- 点缀色高频用于：发光标识、能量体、灯笼/灯光、地面反光条
- **饱和度**：整体中低饱和，仅发光处高饱和。避免通篇高饱和

## 七、形式与构成

- **剪影可读性**：中景与中远景主体的外轮廓在缩小到缩略图时仍能辨认。轮廓优先于细节
- **节奏疏密**：前景极疏（仅低矮物体）→ 中景密（叙事中心之一+引导）→ 中远景密（叙事中心之一）→ 远景疏。疏密交替，不平均分布
- **重复与阵列**：立柱、塔楼、屏幕、旗帜、灯具沿透视线阵列排布，制造韵律与纵深刻度。**阵列本身要有疏密变化和高低错落**，等距等高的阵列会重新引入呆板感
- **体量对比**：必有一个远大于人尺度的巨物（天体、巨兽、地标、穹顶），位于**中景或中远景**且**偏置于一侧**，建立压迫感与史诗感
- **纵深梯度**：从中景到远景至少 **3 个可辨识的纵深层**，靠剪影叠压与大气透视区分
- **信息密度分配**：视觉复杂度集中在中景与中远景，前景只有低矮物体，远景靠大气透视简化

## 八、风格与渲染

- 高品质**游戏 CG 概念场景 / 三维渲染质感**，介于写实与风格化之间
- 表面质感明确：金属、混凝土、石材、湿地面、发光介质各有辨识度
- 细节精度高但不碎，服从整体形体
- 英文写法：`AAA game cinematic key art, 3D rendered concept environment, physically based materials, unreal engine 5 quality, highly detailed yet clean silhouette reading`

## 八点五、场景内标识 vs 叠加文字（易错，务必区分）

规范禁止的是**叠加在画面之上的 UI 层文字**，不是场景里客观存在的标识物。案例中4/7 张都有大量场景内文字（周年庆的 CROSSFIRE 立牌阵列、赏金爆破的弹幕屏、灵音都市的霓虹招牌、流浪地球的倒计时屏）。

| 类型 | 是否允许 | 说明 |
|---|---|---|
| **场景内实体标识**（diegetic） | ✅ 鼓励 | 广告牌、竖幅旗帜、LED 屏、集装箱喷涂编号、地面警示线、器材箱印字。它们是**三维物件**，有透视、有材质、接受光照、会被遮挡和反光 |
| **叠加层文字**（non-diegetic） | ❌ 禁止 | 平贴在画面上的标题、字幕、水印、按钮、图标、HUD。无透视、不受光 |

写提示词时若需要品牌标识（如 CFM / CROSSFIRE），必须显式说明它是**实体物件**：
`CFM branding on physical LED billboards and vertical fabric banners, signage integrated into the 3D environment with correct perspective and lighting, not overlay graphics`

对应地，负面提示词里删掉笼统的 "text / logo"，只保留 `overlay text, subtitle, watermark, UI elements, buttons, icons, HUD, flat graphics pasted on image`。

**标识的构图职能**：竖幅旗帜与广告牌是绝佳的**阵列韵律**和**引导**工具（案例高频用法），应布置在**中景或中远景的两侧**，而非中央留空区；前景若放标识物只能是矮小立牌（高 1–2m，见第九节近景清单），不可做成高大结构。

## 九、角色承载区规范（来自 4 张带人物标记案例的实测）

来源：`大厅图片（带人物）/` 下 4 张（流浪地球 / 灵音都市 / 周年庆 / 封神榜）。这些图带角色仅为**标示角色实际站位与尺度**，用于反推场景约束。

> **生成时绝不画人物。** 这批参考图的用途是让你知道"哪里要给角色让位"，而不是让你把人画出来。负面词中的 no characters 始终生效。

### 角色站位与占位

- 角色立于**画面中央区、地平线以下的地面上**，脚底落在画面高度约 **85%–92%** 处
- 角色高度约占画面全高的 **65%–80%**，头部上缘接近画面上部
- 横向占据中央约 **8%–12% 宽度**，但其**左右各需再留一倍余量** —— 这就是"中央 30% 横向留空"的真正来源

### 九之一、角色区明度下限（硬指标）

**角色周围的场景明度不得过暗**，否则角色轮廓糊进背景、辨识度丢失。

实测角色带（画面横向 45%–55%）平均明度：流浪地球 **117**｜灵音都市 **115**｜周年庆 **129**｜封神榜 **133**

- **硬性下限：角色带平均明度 ≥ 110（0–255 灰阶），目标区间 115–135**
- 角色带明度**必须高于左右最外侧前景**（实测差值 +26 / −5 / +22 / +1，角色区从不明显暗于两侧）
- **这与"两侧压暗"不冲突**：压暗的是画面最外侧 0–20% 的前景框架，角色所在的中央区始终明亮
- 手段：让中景光源、地面反光、天光或氛围光落在角色站位区域；**禁止**把角色站位区做成阴影区、暗部或逆光剪影区

提示词写法：`the central standing zone kept clearly illuminated at medium-high brightness for figure readability, never in shadow, ambient and bounce light filling the middle band, only the outermost foreground framing pushed dark`

### 九之二、近景克制与物体密度分布（硬指标）

**实测边缘密度（细节繁复度）4/4 张一致**：

| 图 | 上部 40% | 中段 | 下部 |
|---|---|---|---|
| 流浪地球 | 27.2 | **30.4** | 28.3 |
| 灵音都市 | 22.0 | **33.6** | 22.5 |
| 周年庆 | 21.6 | **35.8** | 24.5 |
| 封神榜 | 23.1 | **28.8** | 25.2 |

**结论：4/4 张都是中段密度最高，上下都更低。物体必须集中在中远景。**

规则：

1. **前景不放任何物体**：大中小一律禁止。前景的内容 = 地面铺装 + 暗部渐变 + 贴地光影 + 薄雾（见第五节地面小节）
2. **物体密度集中在中景与中远景**：主要的结构、阵列、建筑群、装置都堆到地平线上方区域。物件只出现在中景（每侧至多一组）与中远景
3. **巨物只能放在中景或中远景**，靠距离建立体量感，禁止贴近中央站位区

提示词写法：`foreground completely empty of objects, all props and structures placed in the midground and mid-background around and above the horizon, the near ground carries only paving texture, light bands and reflections`

### 九之三、脚下地面平整（硬指标）

中央地面必须是**平整、连续、可站立**的。

实测脚下中央区边缘密度：19.0 / 19.4 / 33.0 / 31.9 —— 均低于各自图的中段密度，即**脚下始终比中远景更平整**。

- 地面材质：大块规整铺装（石板 / 金属板 / 混凝土分格 / 瓷砖），**分格纹路可以有，起伏不可以有**
- **禁止**在中央站位区出现：碎石堆、大幅裂缝隆起、陡坡、台阶断差、密集杂物、深水、剧烈起伏的自然地形
- 允许且鼓励：平整铺装的**分格线与透视网格**（最强引导工具）、**薄层积水的镜面反光**（薄水膜不破坏平整感，还能把中远景倒映下来）、轻微沙尘或落叶覆盖
- 若题材本身是废墟 / 荒野，把破损、碎块、裂缝**推到中央区之外的两侧或中远景**，中央保留一块平整地坪

提示词写法：`the central ground is flat, level and continuous, large regular paving with clean grid seams, no rubble, no cracks, no steps, no slope, no clutter underfoot, optional thin water film for mirror reflection, any debris or damage displaced to the sides and mid-background`

### 九之四、与既有规范的关系（防止自相矛盾）

| 既有规范 | 与角色区规范的关系 |
|---|---|
| 中亮边暗 | **一致且强化**。角色区就是那个"亮的中间带"，明度下限 110 |
| 中央 30% 横向留空 | **一致**。留空正是为角色让位；现补充"留空区还必须够亮、够平、够空" |
| 两侧压暗收边 | **一致**。压暗只作用于最外侧 0–20%，绝不蔓延到中央 |
| 叙事重心在中远景 | **一致且强化**。实测中段密度最高，近景必须克制 |
| 地平线 30%（从底部量，规范图地面区） | **一致**。角色脚底在画面高 85–92%，处于下部 30% 的地面区域内；角色站位紧贴核心区内缘 |

## 十一、写提示词前的自检清单

逐条打勾，任一条不满足则重写：

**规格与构图（功能分区）**
- [ ] 声明了超宽画幅 2.57:1 / 6532×2538
- [ ] **视觉核心区明确**：宽 23% 的纵向带，左版 20%–43% 或右版 53%–76%；**方案一、二必须左版**
- [ ] **主体物/视觉焦点/画面核心位于核心区内**（中景或中远景层）
- [ ] 角色站位区（横向 45%–55%、核心区内缘旁）近处横向留空，但纵深处要有内容
- [ ] **地平线明确写为从画面底部向上约 30%**（28%–35%，均从底部量），且写出了具体百分比与量取方向
- [ ] 地面占据画面下部约 30%（地面区），有分格铺装或反光材质防空
- [ ] **消失点恰好落在地平线上**（纵向对齐），横向落在核心区内（左版 25%–40% / 右版 60%–75%）
- [ ] **相机为平视或微弱仰视（仰角 0°–5°），全文无任何俯视表述**，焦段24–35mm
- [ ] **正文无任何桥类词汇**（桥/天桥/连廊/栈桥/bridge/walkway/overpass 等），负面词含桥类

**前景与地面（逐条核）**
- [ ] 前景**不放任何物体**（大中小全禁），只有地面 + 暗部渐变 + 光影 + 薄雾
