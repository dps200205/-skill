# 创意扩展与参考图融合方法论

---

## 一、模糊词转译表

用户的创意描述里几乎必然有模糊词。**不要把模糊词原样抄进提示词**——生图模型对形容词无感，对名词和物理描述敏感。转译规则：

| 用户说| 不要写 | 转译为有画面感的字段 |
|---|---|---|
| 科幻感 / 未来感 | "sci-fi feeling" | 全息投影层、外露的能量导管、悬浮金属平台、无缝白色曲面、蓝色数据流光栅|
| 很燃 / 热血 | "epic" | 逆光爆闪、上升的火星粒子、猎猎作响的旗帜阵列、地面裂缝溢出的橙红熔光 |
| 神秘 / 幽玄 | "mysterious" | 低照度冷雾、光源不可见的漫射光、半掩的巨门、悬浮符文环、深处的一点微光 |
| 高级 / 有质感 | "high-end" | 低饱和大面积统一色调、单一强光源、湿润反光地面、克制的镜头光晕、精准的材质区分 |
| 宏大 / 史诗 | "epic scale" | 超人尺度巨物 + 微小尺度参照物（远处的小型载具/栏杆/台阶）并置、多层纵深递退 |
| 温暖 / 治愈 | "warm" | 低角度金色侧光、暖黄灯笼阵列、飘落的暖色花瓣或落叶、柔和的雾气扩散 |
| 压迫 / 危险 | "dangerous" | 上方压顶的巨型结构、倾斜下沉的地面裂痕、深红警示光的间断闪烁、逆光巨影|
| 赛博 / 都市 | "cyberpunk" | 高密度霓虹招牌、湿滑倒影街面、纵向堆叠的建筑体块、荧光单色主导 |
| 国风 / 东方 | "chinese style" | 斗拱飞檐、朱红立柱、汉白玉台基、纹样浮雕、留白式远景山峦|
| 干净 / 简洁 | "clean" | 减少中景元素数量至2–3 个、加大留空面积、统一材质、削弱氛围粒子 |
| 空灵 | "ethereal" | 高明度低对比、大面积雾化远景、垂直光柱、悬浮静止的碎块 |
| 破败 / 废墟 | "ruined" | 断裂钢筋外露、结构性倾斜、植被侵入缝隙、局部积水、剥落的表面涂层 |

**转译原则**：形容词 → 具体物件 + 物理属性 + 空间位置 + 光的行为。

## 二、创意扩展的八个方向

拿到创意后，沿这些轴补足缺失信息。用户往往只给了 1–2 个轴，其余需要主动补全（补全时选择与已给信息最协调的选项）。**轴 1 和轴 2 是重点轴**：

1. **元素提取与发散（重点轴）**——提取用户输入与参考图中的元素，**发散出新的合理元素**：同类延展（给了能源塔→补充能环、输能管线、冷却鳍片）、功能补全（有塔→补基座设施、检修平台、全息控制环）、生态补全（有主体→补与之共生的次级物件）。新元素必须与题材逻辑自洽
2. **构图与引导发散（重点轴）**——在符合大厅制作规范的前提下，对构图进行发散：
   - **元素摆放与组合**：让原有元素与新元素尝试不同的位置关系与组合方式（主体在核心区内的升降、并置、环绕、悬吊、嵌套）
   - **引导方式发散**：让地面上或周围环境中的元素与纹理形成**合理自然的引导**，指向画面视觉中心——直线透视汇聚、**曲线引导**（弧形灯带、弯曲甬道、环流纹理、弧形排列的结构）、序列引导（阵列递退）、明暗引导（光带指向）、色彩引导（点缀色集中在视觉中心）
3. **世界观外壳**——这是哪里？什么文明阶段？（太空站/ 废土都市 / 仙山楼阁 / 异星洞穴 / 竞技殿堂）
4. **事件感**——画面正处于什么瞬间的"前一刻"或"后一刻"？（爆发前的静默 / 庆典进行中 / 战后余烟）
5. **尺度锚点**——用什么建立"大"？巨物是什么，参照小物是什么
6. **空间结构**——开放外景 / 封闭内景 / 半开敞（穹顶、观景台、巨门内外），层叠 / 挑高 / 下沉 / 环绕
7. **时间与天候**——什么时段？什么天气？直接决定光的方向和色温
8. **氛围介质**——空气里飘着什么？（雪 / 落叶 / 火星 / 尘 / 樱花 / 数据碎片 / 灰烬）

**扩展的纪律**：补细节不等于堆东西——核心区内的主体保持 1 个核心标志物，中远景结构物 2–3 组，超过就乱了，也会挤占角色留空区。

## 三、参考图融合方法

### 核心思路：拆维度，不描述内容

用户上传的参考图往往彼此风格不搭（这就是"零散"的含义）。**不要试图把三张图的内容拼在一起**——那会出四不像。正确做法是：每张图只抽取一个维度，让它们在不同维度上叠加，互不冲突。

### 五个可抽取维度

| 维度 | 抽取什么 | 引用句式示例 |
|---|---|---|
| 结构 / 形态 | 建筑体块关系、轮廓走势、结构逻辑 | "参考图一的阶梯式堆叠建筑体块与外露桁架结构" |
| 材质 / 质感 | 表面属性、新旧程度、反射特性 | "参考图二的湿润混凝土地面与哑光金属饰面质感" |
| 配色 | 主色 + 点缀色关系 | "参考图三的深青主调搭配荧光橙点缀的配色关系" |
| 光氛 | 光源类型、方向、软硬、色温 | "参考图一的顶部漫射天光与低对比软阴影氛围" |
| 元素形态 | 具体符号性物件的造型语言 | "参考图二中悬浮环状装置的造型语言" |

### 铁律：参考图一律视为素材图

**不分类。** 所有参考图——无论横构图竖构图、照片还是渲染图——都只提供"画什么"，不提供"怎么摆"：

- **绝不引用**参考图的**镜头感**（视角、焦段感、纵深处理）
- **绝不引用**参考图的**地平线位置、构图布局、明暗分布**
- 构图参数（核心区位置、地平线 30%、相机角度、光比趋势）**一律从规范文件取值**
- 即使是横构图的优秀大厅图也不例外
- 若参考图带有灰底单体特写、居中构图、反向明暗等倾向，提示词里明确切断："作为场景元素融入场景，不做居中特写，不保留原图构图与明暗分布"

### 分配策略

- 每张图**只指派 1–2 个维度**，避免多张图争抢同一维度导致模型混淆
- 优先给参考图指派它最突出的维度
- 如果两张图在同一维度上冲突（比如两张图配色完全相反），只取其中一张，或明确说明"以参考图一的配色为主，参考图二仅取结构"

### 编号规则

- **编号 = 用户上传顺序**。第一张 = 参考图一
- 用中文数字："参考图一 / 参考图二 / 参考图三"
- 英文版用：`reference image 1 / reference image 2`
- 提示词正文里直接写实际内容，**不要保留任何括号占位符**

### 4 段方案中的引用递减

参考图的约束力随离散度递减：

| 方案 | 参考图用法 |
|---|---|
| 方案一 | 全部参考图、全部维度都引用，紧贴 |
| 方案二 | 引用全部图，但松一档（如"参考图二的材质倾向"而非"完全一致的材质"） |
| 方案三 | 只引用 1–2 张最核心的图的 1–2 个维度，其余维度自由发挥 |
| 方案四 | 仅保留参考图的**气质/情绪取向**，不再做具体维度绑定。可写"整体气质延续参考图一的冷峻工业感" |

## 四、四段方案的差异化手法

避免 4 段写得太像。每段至少要在下列手法中动1–2 项。

**重要**：这些手法是你**内部规划差异**用的思维工具，**绝不能写进提示词正文**。提示词里只写该方案最终的画面状态，不写"从什么改成什么"。

**方案一（极低离散）**：最贴近用户原始描述与参考图，几乎不加新元素。构图用规范默认形态：直线透视引导、主体立于核心区内、中景引导结构陪衬。**视觉中心强制左版**。

**方案二（低离散）可动的**：
- 加入**少量新元素**（1–2 个，从轴 1 发散：同类延展或功能补全），仍以原有输入元素为主
- **尝试不同的构图**：元素在核心区内的摆放方式变化（如主体从"矗立"改为"半嵌于建筑中"、"顶部伸出画面上缘"、"被环状结构围绕"），次要内容区元素的组合关系变化
- 引导方式可做小变化（直线汇聚 → 直线+局部弧形灯带）
- **视觉中心强制左版**

**方案三（中离散）可动的**：
- **原有内容与新元素结合**（新元素 2–4 个），尝试**不同的构图与引导**——如曲线引导（弧形甬道、环流纹理、弧形结构阵列）
- **改变空间结构**（开放外景 ↔ 半开敞内景 / 层叠平台 / 下沉广场 / 环廊）
- 加入**特殊艺术效果**（体积光柱、全息粒子流、能量光轨、风格化发光）
- 视觉中心自由（左版右版均可，建议与方案四一左一右）

**方案四（高离散）可动的**：
- 在符合大厅制作规范的前提下，原有内容与新元素**深度结合**，构图、引导、空间结构大幅重构
- 加入**更强更特殊的艺术效果与夸张特效**：能量爆发、时空扭曲、大规模粒子、超现实悬浮、非自然天象
- 可更改氛围与灯光（更戏剧化的光比、更浓烈的色彩、更强的风格化）
- 视觉中心自由

**方案四"夸张"的边界（务必分清）**：

| ✅ 允许夸张 | ❌ 不许越界 |
|---|---|
| 光比更戏剧化 | 中央站位区仍须明亮，不能为了戏剧感把中央做成暗部 |
| 体量对比更极端 | 巨物仍须放在中景或中远景的核心区内，不能挪到近景贴着中央 |
| 色彩更浓烈、饱和更高 | 仍是单一主色调 + 一组点缀色，不做多色混战 |
| 物理更超现实（悬浮、解体、倒置） | 中央地面仍须平整可站立，不能悬空或碎裂 |
| 元素更繁复、信息量更大 | 前景仍须不放任何物体，繁复度堆到视觉核心区与中远景 |
| 构图张力更强 | 仍是功能分区、地平线 30%、角色区横向留空、相机平视或微弱仰视 |

**永不改动的**：所有制作规范 —— 功能分区（方案一二左版）、地平线 30%、前景不放任何物体、五层结构、角色区明亮平整留空、非对称。方案四也必须过完自检清单全部条目。

## 五、中远景填充素材库（防空旷速查）

画面显空的根因几乎总是中远景漏写。按场景类型取用，每段至少选 **2–3 组**，并交代它们的**前后遮挡关系**与**至少 3 个纵深梯度**：

| 场景类型 | 中远景可填充的结构物 |
|---|---|
| 都市 / 基地 | 塔楼阵列、起重机群、通风塔、广告牌阵、变电构架、高层平台、远处楼群剪影 |
| 港口 / 军事 | 龙门吊列、集装箱山、舰体上层建筑、雷达塔群、灯塔、船坞门架、系泊浮标 |
| 遗迹 / 墓葬 | 塔林、残柱阵、层叠台基、崖壁凿窟、石阶递退、巨型雕像群、夯土城垣 |
| 自然 / 荒野 | 山体层叠（近中远三层）、峡谷侧壁、巨树群、岩柱林、瀑布、冰川断面、沙丘脊线 |
| 科幻 / 太空 | 悬浮平台群、环形结构、能量塔、飞行器航道、穹顶骨架、远处星体与舰队剪影 |
| 室内 / 洞穴 | 层叠拱券、廊柱递退、悬吊平台、钟乳石群、机械管廊、多层看台、穹顶肋骨 |

**通用填充手法**（任何题材都适用）：
- **纵深剪影叠压**：3 层以上前后叠压的轮廓，近深远浅
- **阵列递退**：同类结构沿纵深缩小排布，但**高低错落、疏密不均**
- **避免横向跨越结构**：桥、栈道、连廊、管廊这类横跨画面的长条结构**极易被模型生成为莫名其妙的桥**，一律不用。需要连接左右或压住上部空区时，改用高低错落的塔楼轮廓、层叠楼体剪影、悬浮平台群或分层云带/光带
- **偏置巨物**：一个超尺度物体占据一侧上方，仅露局部。**必须位于中远景或更远**，靠距离建立体量感，不可贴近中央站位区
- **云层/雾层结构化**：即使是天空，也用分层云带、光柱、飞鸟群做出内容

**注意**：以上填充手法全部作用于**中景（核心区内）与中远景**。前景永远不放任何物体，前景设计只有地面三要素（引导/纹理/结构），中央站位区保持平整空旷。

## 六、地面设计速查（前景的唯一内容）

前景不放任何物体，前景设计 = 地面设计。每段提示词必须把这三类写全：

### 地面引导（至少选 2 种，终点都是视觉核心区主体）

| 手法 | 说明 | 英文 |
|---|---|---|
| 分格缝透视汇聚 | 板块接缝向纵深汇聚到消失点 | paving seams converging toward the vanishing point |
| 嵌入式发光导引条 | 灯带/光缝嵌入地面，直线或弧线指向主体 | embedded luminous guidance strips in the ground pointing toward the main subject |
| 光带扫射/长影 | 一道光或长影横扫地面对角线 | a sweeping light band and long shadows cast across the ground |
| 反射引导 | 湿润/高反射地面倒映主体与光源 | subtle ground reflections mirroring the main subject and light sources |

### 地面纹理细节（接缝必须 + 嵌线图案选 1 种）

- 必选：**大板接缝**（唯一必须纹理）
- 选 1 种嵌线图案：菱形嵌块 / 几何折线光带 / 同心涟漪纹 / 裂纹透光 / 六边格 / 抽象几何纹理
- 可加：相邻板块明度微差、局部湿润反光、极轻覆盖物（花叶/薄尘/细雪，点到为止）
- 铁律：**所有纹理服从同一消失点**，禁止随机纹理

### 地面结构

- 超大规格板块（2m+），禁止小砖碎拼
- 平整连续，无起伏台阶断差
- **中央最简**：纹理强度中央最低、向两侧与中远景渐强，疏密梯度本身也是引导

## 七、常见失误

- ❌ 把模糊形容词直接翻译进英文提示词 → 模型无响应
- ❌ 四段写成四个不同创意 → 用户要的是同一创意的离散度梯度
- ❌ **四段只在氛围/光影/时间上发散 → 发散重心必须是内容、构图与构成：新元素 + 元素组合 + 引导方式**
- ❌ **提示词里写"（同一场景，时段改为黄昏）"这类跨方案说明** → 四段必须独立自包含
- ❌ 为了"扩展"往视觉核心区堆多个主体 → 核心区内只保留 1 个核心标志物，中远景结构 2–3 组
- ❌ **方案一或方案二把视觉中心放到了右侧 → 方案一、二强制左版（视觉核心区在左）**
- ❌ 试图把参考图内容拼贴 → 出四不像，应拆维度叠加
- ❌ **引用参考图的镜头感/地平线/构图 → 参考图一律视为素材图，只取内容维度**
- ❌ 提示词里留了"（此处填写具体内容）"这类占位符 → 必须写实际内容
- ❌ 忘记声明超宽比 → 模型出 16:9，构图全废
- ❌ **主体物放正中 → 主体必须在核心区内（左版 20–43% 或右版 53–76%），消失点落在核心区内**
- ❌ **地平线量取方向或数值写错 → 一律从画面底部向上约 30%（地面占下部约 30%，规范图地面区实测）**
- ❌ **写出桥、天桥、连廊、栈道等 → 模型会疯狂加桥；正文不写桥类词，桥类全进负面词**
- ❌ **前景放任何物体 → 一律禁止（大中小全禁），前景只有地面、暗部渐变、光影、薄雾；高大结构只能去中景**
- ❌ **相机写成俯视/俯角 → 一律平视或微弱仰视（≤5°），严禁俯视**
- ❌ **只写了前景和中景，中远景一句没写 → 画面必然空旷**
- ❌ **地平线上方留成大片空天空 → 必须被中景上部/中远景结构填满**
- ❌ **引导没有指向视觉中心 → 地面纹理与环境元素必须形成自然引导，终点是核心区主体**
- ❌ **把中央做成阴影区或逆光暗部 → 角色会糊进背景，中央必须明亮**
- ❌ **中央地面写成碎石地、裂缝、陡坡、台阶 → 角色无法站立，中央必须平整**
- ❌ **因为参考图带人物就把人画出来 → 绝不生成人物**
- ❌ 方案四为了发散破了制作规范 → 图不可用。发散只作用于内容、构图、构成与艺术效果
- ❌ 只给英文或只给中文 → 两版都要给
