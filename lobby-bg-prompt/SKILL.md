# 大厅背景图提示词管线

把用户零散的创意 + 参考图，转成4 段符合大厅背景图制作规范的提示词。

## 核心目标

用户不要一段"好看的画面描述"，用户要的是**能出正确规格图**的提示词。大厅背景图是 UI 与角色的承载体，不是插画：前景不放任何物体、聚焦于地面设计（引导/纹理/结构），视觉核心区承载主体物，角色紧贴核心区内缘站立，地面占据画面下部约 30%。这些是硬约束，任何创意都必须服从。

七条最容易做错、必须时刻警惕的：
- **功能分区**：主体物/视觉焦点必须在核心区内（宽 23% 的纵向带，左版 20–43% 或右版 53–76%）；**方案一、二强制左版**，方案三、四自由
- **前景不放任何物体**（大中小全禁），前景设计就是地面设计：地面引导（分格缝汇聚/发光导引条/光带扫射/反射，至少 2 种）、地面纹理细节、地面结构；两侧上方必须通透
- **相机平视或微弱仰视**（仰角 ≤5°），**严禁任何形式的俯视**
- **禁止对称构图**（项目明确取向，见规范第二节）
- **地平线从画面底部向上约 30%**（规范图地面区实测），上部区域要被中景上部/中远景结构填满，不是空天空
- **一切引导指向视觉核心区**：消失点在核心区内且恰好落在地平线上；地面纹理与环境元素形成自然引导
- **中央站位区必须明亮、平整、空**（明度 ≥110、地面无碎石起伏、近景不堆物），见规范第九节
- **发散针对内容、构图与构成**，规范类约束四段一字不改

**关于带人物的参考案例**：`大厅图片（带人物）/` 里的图带角色，是为了标示角色实际站位与尺度，从而反推场景该在哪里让位。**生成时绝不画人物。**

**产出即交付**：4 段提示词直接写在回复里让用户复制。不要写成文件，除非用户要求。

## 工作流程

### 第1 步：读规范（必做）

读`references/lobby-spec.md`。这是从项目优秀案例与规范图量化提炼的制作规范，包含功能分区、地平线位置、相机参数、层次关系、光比数据。**不要凭通用美术常识替代它**——里面的数值是实测的。

### 第 2 步：解析用户输入

**创意想法**：抓取题材、情绪、时代/世界观、关键物件。用户给的往往是模糊词（"科幻感"、"很燃"、"神秘一点"），把它们转成有画面感的具体字段——见 `references/expansion.md` 的模糊词转译表。

**参考图**：如果用户上传了图，逐张看，判断每张图**能贡献什么**（结构 / 材质 / 配色 / 光氛 / 元素形态），而不是描述它画了什么。给每张图编号，编号顺序 = 用户上传顺序。

**参考图一律视为素材图**：**绝不取用参考图的镜头感、地平线位置、构图布局与明暗分布**——这些全部从规范文件取值。参考图只提供"画什么"（结构/材质/配色/光氛/元素形态），不提供"怎么摆"。即使是横构图的优秀大厅图也不例外。若参考图带有灰底单体特写、居中构图、反向明暗等倾向，提示词里明确切断："作为场景元素融入，不做居中特写，不保留原图构图与明暗分布"。

如果用户没给参考图，跳过引用部分，正常生成 4 段。

如果创意想法只有一两个词、完全无法判断题材方向，问一次澄清再动手；否则直接做，允许合理假设。

### 第 3 步：写 4 段提示词

4 段是**同一创意的4 个离散度档位**，发散的核心是**画面内容、构图与构成**——先发散出新的内容与设计元素，再让原有元素与新元素在画面里做合理组合，形成新的构图与画面效果。**不是只换氛围、光影、时间**：

| 方案 | 离散度 | 定位 | 视觉中心 |
|---|---|---|---|
| 方案一 | 极低 | 最贴近用户原始描述 + 参考图，几乎不加新元素。安全底稿 | **左版** |
| 方案二 | 低 | 以原有元素为主，加入**少量**新元素；**尝试不同的构图**（元素摆放与组合方式变化） | **左版** |
| 方案三 | 中 | 原有内容与新元素结合，尝试**不同的构图与引导方式**（如曲线引导），**改变空间结构**，加入特殊艺术效果 | 自由 |
| 方案四 | 高 | 原有内容与新元素深度结合，构图、引导、空间结构大幅重构，**加入更强更特殊的艺术效果与夸张特效**，可更改氛围与灯光 | 自由 |

### 铁律一：离散度只作用于「内容与艺术效果」，绝不作用于「制作规范」

把两类东西彻底分开，这是整个 skill 最重要的一条：

| 可以随离散度自由发散 | 四段完全一致、一字不改 |
|---|---|
| 题材、世界观外壳、叙事事件 | 超宽画幅 2.57:1 / 6532×2538 |
| 具体物件、建筑形制、材质 | 地平线从底部向上约 30% |
| 配色方案、光源类型、时段天候 | 功能分区（核心区位置按方案约束） |
| 氛围介质、粒子、特效 | 非对称构图（禁止镜像对称） |
| 设计元素的新增与组合、构图与引导方式 | 角色站位区横向留空、明亮、平整 |
| 艺术风格强度、写实↔风格化、超现实手法 | 五层结构齐全、中远景填满 |
| 夸张的体量对比、戏剧化光比 | 前景不放任何物体、角色区明亮平整（见规范第九节） |
| 色彩饱和强度、对比强度 | 相机平视或微弱仰视、24–35mm、深景深 |

**方案四允许的"夸张"是艺术层面的**：更强的戏剧光、更极端的体量、更超现实的物理、更浓烈的色彩、更强的风格化。**不允许的是规范层面的越界**：不能因为要发散就改地平线、破留空、放弃非对称、让角色区变暗、往近景堆东西。

判断标准一句话：**发散"画什么""怎么组合"和"画得多猛"，不发散"放在哪个区""地面占多少""相机怎么架"。**

### 铁律二：四段必须彼此独立、自包含

每段提示词都是**一段可以单独复制出去使用的完整描述**。用户会把某一段单独发给生图模型，模型看不到其他段。

**严禁**在提示词正文或标题旁写任何跨方案的对比、增量或改动说明。禁止出现的写法：

- ❌ "（同一场景，时段推至黄昏，焦段收至 35mm，构图改为非对称）"
- ❌ "（保留核心内核，中景主体由建筑换为自然造物）"
- ❌ "（提取情绪内核，换世界观外壳为……）"
- ❌ "同方案一，但……" / "在方案二基础上……" / "延续上述构图……"

**正确做法**：直接从画面本身写起，把该方案的全部设定当作唯一存在的设定完整交代一遍。四段之间的差异让用户自己看出来，不要解释。

方案标题只写「方案N（离散度：X）」，标题后不加任何括号说明。离散度的差异体现在**内容本身**，而不是靠文字注解。

### 第 4 步：每段提示词的写法

每段固定包含这几块，按顺序：

1. **画面主体与题材**（融入扩展后的具体字段）
2. **参考图引用**——写成"参考图一的金属管线结构与冷灰配色"这类句式，明确取用哪一维度。不要写括号占位符，直接写实际内容
3. **构图与镜头**——写明**视觉核心区在左或在右及横向范围**（方案一、二必须左版 20–43%）、**地平线从画面底部向上约 30%**、地面占下部约 30%、**相机平视或微弱仰视（仰角 ≤5°，严禁俯视）**、焦段、**消失点恰好落在地平线上且横向落在核心区内**、角色站位区（中轴附近）横向留空
4. **引导与非对称声明**——写明引导方式（地面纹理/环境元素/明暗/曲线等如何指向核心区主体）；显式写出至少 3 个打破对称的手段（核心区偏置、消失点在核心区内、地面光影纹理左右不等、两侧次要内容区不同类），并写 `asymmetrical composition, avoid mirror symmetry`
5. **层次**——前景 / 中景 / **中远景** / 远景 / 氛围介质，五层都要交代。要点：
   - **前景不放任何物体**，用地面三要素做前景设计：**引导**（分格缝透视汇聚/嵌入式发光导引条/光带扫射/反射引导，至少 2 种）+ **纹理细节**（板块接缝 + 一种嵌线图案）+ **结构**（大板铺装、平整、中央最简），两侧上方通透
   - **主体物放在核心区内**（中景或中远景层），写明在哪一层
   - **中景承担画面引导**（结构边缘线引向核心区主体）
   - **中远景必须写出 2–3 组具体结构物**并交代前后遮挡与纵深梯度，地平线上方不能是空天空
6. **角色承载区三条**（每段必写，见规范第九节）——
   - 中央站位区**明亮、不在阴影中**（明度目标 115–135），压暗只作用于最外侧 0–20%
   - **前景一件物件都不放**，巨物一律放中景或中远景，物体密度集中在中景与中远景
   - **中央地面平整连续**，无碎石/裂缝/台阶/陡坡/杂物，破损推到两侧或中远景
7. **光影与色彩**——横向"中间亮、两侧暗"的趋势 + L2/L3/L4 的明度台阶
8. **质感与风格**——渲染感、精度、材质倾向
9. **技术参数**——超宽比 6532×2538（≈2.57:1）、高细节、无叠加文字无水印无 UI、**无人物**

同时给**中文版 + 英文版**：中文给用户核对理解，英文给生图模型实际使用。英文不是中文的逐字直译，要用生图模型吃得准的短语堆叠式写法。

结尾附一段**负面提示词**（4 段共用），从规范文件里取。

**首次执行或不确定写法时，读 `references/example.md`** ——里面有一次完整流程的示范输出，包含4段的递进关系、参考图引用递减、以及每段该写到什么颗粒度。照它的密度写。

##硬性红线

写每段提示词前，逐条对照 `references/lobby-spec.md` 末尾的自检清单。以下任一条不满足，重写那一段：

- **功能分区**：主体物/视觉焦点必须位于核心区内（宽 23% 纵向带，左版 20–43% / 右版 53–76%）；**方案一与方案二强制左版，方案三、四自由（建议左右各一）**
- 角色站位区（横向 45%–55%、核心区内缘旁）近处不放大体积遮挡物，纵深处必须有中远景内容
- **前景不放任何物体**（大中小全禁）；前景设计 = 地面设计（引导/纹理/结构三要素写全，引导指向视觉核心区主体）；两侧上方必须通透；中大型结构只放中景且每侧至多一组
- **相机平视或微弱仰视**（仰角 ≤5°），**严禁任何形式的俯视**
- **禁止镜像对称**：核心区偏置、消失点在核心区内、高光锚点在核心区内，至少用 3 个破对称手段
- **地平线必须落在从画面底部向上约 30%**（28%–35%，从底部量），地面占下部约 30%，消失点恰好落在地平线上
- **地平线上方必须被中景上部/中远景结构填满**，不允许大面积空白天空
- **一切引导指向核心区主体**（透视线、地面纹理、环境元素、明暗），中景承担画面引导；中远景写出 2–3 组具体结构物
- **中央站位区必须明亮**（不在阴影中，明度目标 115–135），压暗仅限最外侧 0–20%
- **中央地面必须平整连续**，无碎石、裂缝、台阶、陡坡、杂物
- 两侧以暗部渐变收边为主，前景无物件，地面光影与纹理左右不对称
- **正文不使用任何桥类词汇**（桥/天桥/连廊/栈桥/bridge/walkway/overpass），中远景需要连接感时用塔楼轮廓/楼体剪影/悬浮平台等非桥结构，桥类词进负面提示词
- **绝不生成人物**（带人物参考图仅用于理解站位约束）；不能出现叠加层文字/UI（但场景内的实体广告牌、旗帜、喷涂编号是允许且鼓励的，须声明为三维实体，见规范第八点五节）
- 必须写明超宽画幅，否则模型会出 16:9
- **四段提示词彼此独立自包含**，正文与标题不得出现跨方案对比或改动说明
- **发散针对内容、构图与构成**（新元素 + 元素组合 + 引导方式），规范类约束四段完全一致

## 完成后

不写记忆文件，不写产出文件。直接把 4 段提示词交付在回复中，末尾用一句话提示用户：连同参考图一起发给生图模型，建议先跑方案一和方案三对比。
